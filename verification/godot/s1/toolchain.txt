Checks added in the review fixes (tested on a scratch cache with the real archives hard-linked in, and on crafted zips):
  - archive safety fails closed: a file that is not a zip, an empty zip, '..' and absolute paths, and symlink entries are
    all refused before anything is extracted (before, a file that could not be listed passed the check).
  - install stamps detect additions as well as modification: a planted file in platform-tools or in the template
    directory, or a symlink there, triggers a re-extract that removes it; an unknown build-tools/<version> directory is
    removed (Godot would pick the apksigner from it). A re-run after that is a no-op again.
  - an interrupted download keeps its .part file unless curl reports that the server cannot resume (exit 33); with an
    unreachable proxy the 40 MB partial file survived and the next run resumed it and verified the SHA-512.
