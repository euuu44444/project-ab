  ERROR: Defs: res://sim/defs/characters.json does not exist ... (backtrace through Sim.new_game, called from main.gd:35 _ready)
so the run above would have noticed a missing table. (An APK on a device cannot be started here: no device or emulator.)

4. Finding about the export filter (corrects the comment of implementer G)
----------------------------------------------------------------------
godot/export_presets.cfg got include_filter="sim/defs/*.json" in this step (S1 file; test_defs.gd guards it). Implementer G reported that without it the
PCK holds no sim/defs/*.json. That was NOT reproduced: two project copies with include_filter="" (one with the existing .godot cache, one without .godot
and re-imported) both packed all five JSON files with export_filter="all_resources" (Godot 4.7.2 treats .json as a resource) and nothing from tests/.
The filter is kept because it makes the shipping explicit instead of relying on that engine behaviour; the comment in test_defs.gd was corrected and
no longer claims that Godot refuses to export .json files.

Open point for the owner of tools/build_android.sh: add an 'sim definitions' check next to 'atlas assets' (the five sim/defs/*.json and the 38 sim
.gdc files are in the APK, no tests/ entry), so that a future export change cannot drop them unnoticed. Not done here because the script is outside the
S3-owned file list.
