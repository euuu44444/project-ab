2. Compiler and linker commands that native/SConstruct checked (flag-guard-<config>.txt of the run; paths shortened)
----------------------------------------------------------------------

Floating point: -ffp-contract=off -fno-fast-math, -O2 on every target (also template_release; godot-cpp's default would be -O3 there).
Since this round native/SConstruct does not look at CCFLAGS & co one by one (a deny-list that missed CPPFLAGS, the compiler variables, -ffp-model=*,
-mdaz-ftz, ...). It substitutes every variable into the command scons will run and checks the resulting argument list:
  - compile commands of EVERY source file: ours (C++), every godot-cpp object (C++), and the C compile commands ($CCCOM, $SHCCCOM);
  - the link command of the library (-ffast-math at link time would pull in crtfastmath.o, which sets FTZ/DAZ at load time);
  - the program must be clang++ / clang (host) or the NDK's clang++ / clang (full path); every other argument starting with - or @ must be on the
    allowlist printed at the top of each file (-D<NAME>, -I<path> are accepted, file names are accepted); the compile commands must contain
    -ffp-contract=off, -fno-fast-math and -O2 and the -ffile-prefix-map options; the compiler environment may hold PATH only.
The allowlist and the checked commands are written to <build dir>/flag-guard.txt (copied here with --evidence-dir). 127 mutants of the SConstruct,
of the command line, of the environment and of the godot-cpp checkout, each of which must stop the build, are in guards.txt.

5. No fused multiply-add: disassembly of swarm_fp_probe_mul_add (native/src/fp_probe.cpp: return a * b + c)
